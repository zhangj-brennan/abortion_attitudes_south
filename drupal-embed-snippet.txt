Drupal embed snippet for the State Abortion Landscape map
===========================================================

Paste this into the page body with the "Full HTML" text format (other
formats strip the <script> tag), using Source view in the editor.

The map page posts its rendered height to the parent window; the listener
script below sets the iframe to exactly that height, so there's no blank
space under the source line and nothing gets clipped. It re-fits when the
window is resized or the legend changes. The 900px height is only a
fallback for the moment before the map loads.

<iframe id="abortion-map-embed" src="https://zhangj-brennan.github.io/abortion_attitudes_south/" style="width:100%; height:900px; border:0; display:block; overflow:hidden;" scrolling="no" title="State Abortion Landscape"></iframe>
<script>
(function () {
  var frame = document.getElementById("abortion-map-embed");
  window.addEventListener("message", function (e) {
    if (e.source !== frame.contentWindow) return;
    if (e.data && e.data.type === "brennan-embed-resize") {
      frame.style.height = e.data.height + "px";
    }
  });
})();
</script>
